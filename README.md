# 📋 Daily Task Tracker (Streamlit App)

A simple yet powerful **task management dashboard** built with **Streamlit** to help you plan, track, and complete your daily work efficiently.

---

## 🚀 Features

✨ **Task Management**
- Add tasks with priority, study/project, and task type
- Delete individual tasks or clear all tasks
- Persistent storage using CSV

⏱ **Time Tracking**
- Start, pause, resume, and complete tasks
- Automatic effort calculation (in hours)
- Tracks paused time separately

📊 **Visual Workflow (Kanban Board)**
- PENDING → WIP → DONE flow
- Clean column-based layout for quick tracking

🔔 **Notifications**
- Desktop notification when a task is completed

📌 **Priority Highlighting**
- 🔴 High Priority (1–2)
- 🟠 Medium Priority (3–5)
- 🟢 Low Priority (6+)

📋 **Teams/Email Update Generator**
- Auto-generate formatted task summary
- Copy-paste ready for daily updates
